# 🎩 Альфред — этап 2

Что умеет:
- понимает обычную речь про дела и заметки (мозг — GigaChat);
- 📋 дела: добавить, перенести, переименовать, вычеркнуть, удалить, кнопки «✅» в списке;
- 📝 заметки: записать, найти, изменить часть текста, удалить;
- уточняет, если не понял или нашёл несколько похожих записей;
- «Отмена» сбрасывает незаконченный разговор;
- проверки дел в 10:00, 14:00 и 18:00 (по Москве) с кнопками;
- 🕰️ распорядок: лекции, практики, тренировки, врач, встречи — обычной речью;
- повторения: «каждый понедельник и четверг», «по будням», «до конца октября»;
- переносы, исправления, комментарии, удаление одного занятия или всей серии (с подтверждением);
- кнопки «Сегодня», «Завтра», «На неделю»;
- напоминания: первая лекция за час, следующие за 30 минут, врач и встречи за час, тренировки — без напоминаний;
- утренняя сводка в 10:00, а если есть ранняя лекция — вместе с напоминанием о ней;
- в 19:00 — расписание на завтра;
- остальные разделы меню отвечают, что они в разработке.

## Переменные окружения (Railway → Variables)
- TELEGRAM_TOKEN — токен от @BotFather
- OWNER_ID — твой Telegram ID
- GIGACHAT_AUTH_KEY — ключ авторизации GigaChat

## Запуск
Start Command на Railway: `python main.py`

## Хранилище
Подключи Volume с путём `/data` — база сама окажется там и перестанет стираться при обновлениях.

## Тесты (для разработки)
`pip install -r requirements.txt pytest` → `python -m pytest`
